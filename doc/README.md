# 项目文档

现行文档按聊天窗口命名。聊天用于讨论和实施；同名文档保存该聊天的当前结论与用户主动“收尾”后的阶段记录。跨聊天未完成事项统一放在 [待办清单](TODO.md)。

| 聊天 | 文档 | 用途 |
|---|---|---|
| 00-项目总控 | [00-项目总控.md](00-项目总控.md) | 项目架构、模块入口和运行方式 |
| 01-git | [01-git.md](01-git.md) | Git、旧功能清理与上线前核对 |
| 02-打印 | [02-打印.md](02-打印.md) | 班级打印、多机分配和故障处置 |
| 03-上传 | [03-上传.md](03-上传.md) | 上传路径与 COS 直传排查 |
| 跨聊天 | [TODO.md](TODO.md) | 只列未完成需求、问题和验收事项 |

正式记录由用户主动说“收尾”或明确要求写文档时触发。负责聊天在同名文档的“收尾记录”表中写日期、本次完成、验证与证据、未完成或限制；多轮修改可合并一行，重复收尾修订原行。实际代码差异由 Git 保留，文档不抄逐文件变更。待办只写未完成事项；项目架构变化时更新 `00-项目总控.md`。规则详见 [项目 AGENTS.md](../AGENTS.md)。

整理前的架构、任务文档、变更记录和启动说明保存在 [2026-10-09 归档](archive/2026-10-09-整理前/PROJECT.md)；更早的设计见 [历史设计](archive/开发文档-历史设计.md)。归档用于查出处，不作为当前实施依据。
