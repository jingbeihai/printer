# T002：旧功能退役与冗余代码清理

- 状态：待验收（代码清理与自动化验证完成；部署前数据库核对及真机回归未完成）
- 更新：2026-10-08
- 来源：用户明确要求删除本方案列出的旧功能、迁移逻辑、CSV、模拟器及样例生成器。
- 前置基线：保留当前 T001 的班级作业、多机预分配与人工恢复实现。T001 仍待真机验收；清理不能把它改为已验收，也不能覆盖已有改动。
- 总控本次只更新方案；尚未实施任何代码删除。

## 目标与范围

只保留云端服务与正式 Windows 印务台的现有业务主路径，清除独立 agent 和其他已确认废弃的实现。不新增 CSV 导出或替代模拟器。精简代码不代表删除现有数据库、账号、任务记录、用户 PDF、安装包或历史文档。

## 数据库与历史数据处理

检查发现，当前本地建表定义缺少部分正式功能需要的列，依靠 db.init 的补列逻辑完成，连空数据库首次初始化也会经过该逻辑。因此不能直接删掉全部 ALTER TABLE 代码后结束任务。

- 将当前正式字段一次性写入 SERVER_SCHEMA、当前本地 schema 的 CREATE TABLE 定义，包含运行/休息设置、paused、print_requested、print_requested_at、printer_ids、job_model 等实际仍使用字段。新任务默认使用 class 模型。
- 保留新库初始化、当前版本数据库读写、首次超级管理员创建、现行会话及邀请码初始化；只删除历史升级和角色转换行为。
- 已满足当前结构的数据库原样继续使用，不自动重置账号或清空历史记录。
- 不再支持自动升级缺少必需字段的旧数据库。启动时只读核验必需结构；发现不支持的旧结构，明确报错停止，不尝试 ALTER、删除或重建已有数据。实际旧库升级不属于此次执行授权。
- 已存在的旧角色账号不自动改为新角色，也不能因此获得权限；保留现有正确 user/superadmin 账号的行为。
- 不再自动转换 legacy 任务，也不执行旧任务闸口。历史记录可以查看；未结束的旧任务明确阻止继续下发并提示用户取消后重新提交。实际取消由用户决定，不能批量自动取消或删除。
- job_model 如仍用于识别和拒绝旧未结束任务则保留为数据标识；移除的是旧执行/转换逻辑，不为清理字段破坏历史数据。

## 当前主路径必须可用

- Windows 的 StationRuntime、Executor、CloudSync、Importer 及必要数据库访问继续工作，只删除其旧模式分支。
- /api/agent/sync 和 /api/agent/file/{tid} 仍由正式客户端调用，保留现有地址及 Cookie + client_id 行为；名称带 agent 不代表可删除。Token 单独使用应不再获准访问。
- 登录、注册、用户中心、公司管理、上传、学校预设、统计查看继续可用。注册模板继承 base.html，因此不整批移除 Jinja、公共模板和登录/注册页面。
- 保留云端 PostgreSQL/SQLite、本地 SQLite、磁盘/COS 文件存储；这些是当前能力。
- 保留 WindowsBackend、SumatraPDF、win32print、SNMP、打印休息管理、领取互斥、任务控制和 T001 多机班级分配。
- prototype 是正式界面源码，app/static/desk 是正式产物。使用中的 Tabs、Progress、AlertDialog 及传递引用的 Button 等组件不能删除。
- 当前 Sites/Cloudflare/Vinext 插件仍参与构建，不因历史名称删除；前端构建工具链重构不在此次范围。

- run.py 不再支持 agent；CUPS、业务模拟器、样例生成器、封面、80 张拆组及旧迁移入口不存在，相关代码和专用配置无残留引用。
- 云端旧 GET 引导到正式界面；旧表单 POST 和 /dashboard.csv 不再执行旧功能（无对应路由）；现有会话同步与下载可用，Token 单独鉴权失败。

## 关于“是否已迁入客户端”的说明

- 旧数据库/账号/任务迁移不是一个界面功能。它目前仍分别在共享数据库初始化、云端账号初始化及桌面任务准备中执行；按本方案移除其自动升级/转换能力。
- CSV 导出目前只有云端旧 /dashboard.csv 入口，正式客户端仅有统计查看，并无对应 CSV 下载入口；按用户要求直接删除导出能力，不迁入客户端。

## 实施结果

### 实际修改

- 移除 `run.py agent` 入口、`app/agent_web.py`、`app/maintpdf.py`、根目录 `make_sample.py`，并删除 agent 专用配置、模拟器播种、Linux CUPS 与业务模拟打印后端。`WindowsBackend` 由桌面调度器直接使用。
- 删除旧 `submit`、`queue`、`admin`、`dashboard` 业务模板及关联页面 POST；保留 `/login`、`/register` 和公共模板。旧 GET `/submit`、`/queue`、`/admin`、`/dashboard` 重定向到 `/desk/`；旧表单 POST 返回 405，`/dashboard.csv` 不再注册（404）。
- `/api/agent/sync` 与 `/api/agent/file/{tid}` 地址保留供正式桌面端使用，只接受用户会话和 client_id；`X-Agent-Token` 单独访问返回 401。移除 Token 生成、配置与旧桌面设置迁移代码。
- PDF 合成仅保留当前无封面的班级作业与逐份双面补白，删除封面生成、托盘拆组、模拟故障接口、维护页与旧自动任务闸口；保留 T001 的固定设备归属、故障留原机、人工恢复/确认/重打及打印休息功能。删除 `reportlab` 依赖。
- `SERVER_SCHEMA` 和本地 `LOCAL_SCHEMA` 现直接定义当前字段。移除所有启动时 `ALTER TABLE` 补列；启动只读核验既有结构，缺字段即报错停止。有效当前结构可重新打开，空库可创建。旧角色不自动转换或提升；旧 `job_model` 任务不自动转换或派发，尝试打印时提示取消后重新提交，不自动取消或删除记录。
- 根据当前页面静态依赖图删除 56 个不可达预置 UI 组件，并从 `prototype/package.json` / lockfile 移除仅用于旧组件的 `@shadcn/react`、`cmdk`、`date-fns`、`embla-carousel-react`、`input-otp`、`react-day-picker`、`react-resizable-panels`、`recharts`、`shadcn`。保留页面实际使用的 `Tabs`、`Progress`、`AlertDialog`、`Button` 和机队面板。
- 更新当前架构、开发启动说明、规则文件、文档导航与任务总表。静态构建产物已从 `prototype/dist/client` 同步到 `app/static/desk`，复制时保留了目录原有的其他文件。

### 实际验证

- `python -m unittest discover -s tests`：48 项通过。覆盖 T001 班级作业与 7/7/6 分配、云端上传/COS 降级、客户端领取/同步、旧 Token 拒绝、旧页面路由、旧角色不提权、当前 schema 重启保留数据、空本地库字段及不支持的本地库失败且不改动。
- `npx tsc --noEmit`（`prototype`）：通过。
- `npm run build`（`prototype`）：客户端、服务端编译及 2 条静态路由预渲染完成；随后 Node 在退出阶段报 `uv_async` 断言，命令退出码为 1，故构建未记为通过。生成文件仍已同步到正式静态目录。
- 未启动桌面客户端或云端服务，未访问/修改生产数据库，未执行安装包构建、真实打印、部署、提交或推送。
